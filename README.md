This project builds an end-to-end Data Warehouse (DWH) solution for a Real-Estate Management Company to analyze agent performance and property transactions. The pipeline includes relational database design, ETL processing, Star Schema modeling, and interactive dashboards using Power BI.

Relational Database Design


Star Schema Data Warehouse


ETL Pipeline using Python & SQL
